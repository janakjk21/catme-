# Context folder rules

These files are compact operational memory, not a progress journal.

- Keep `STATUS.md` below roughly 100 lines.
- Keep topic modules limited to stable facts, contracts, constraints, and acceptance criteria.
- Replace stale facts instead of retaining historical versions.
- Put durable choices in `DECISIONS.md` with a date and short reason.
- Do not paste logs, provider responses, long prompts, code, secrets, or conversation transcripts here.
- Link to the detailed implementation reference instead of copying large sections from it.
